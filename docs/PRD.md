# Cầu Hàn (cau-han) — 제품 기획서

> 이 문서는 "왜 이 앱을 만드는가"의 기준이다. 기능을 고르거나, 개선 여부를 판단하거나, 아이디어끼리 부딪칠 때 이 문서를 근거로 결정한다.
> 원칙(3장)과 "하지 않을 것"(8장)은 Max의 승인 없이 바꾸지 않는다. 바꿔야 한다고 판단되면 docs/PLAN_LOG.md에 제안으로 남긴다.

최종 수정: 2026-11-24

---

## 1. 한 줄 정의

**한국 회사에 다니는 베트남 직장인이, 이미 알고 있는 베트남어 한자어(Hán Việt)를 다리 삼아 한국어 어휘를 빠르게 늘리고, 그 단어를 회사에서 실제로 쓰는 문장으로 익히는 앱.**

이름의 Cầu는 베트남어로 "다리"다. 지금은 한자어 어휘에서 시작하지만, 앞으로 듣기와 문장 등 다른 학습으로 넓힐 수 있다.

---

## 2. 왜 만드는가

### 2.1 시장
- 베트남은 한국 밖에서 TOPIK 응시자가 가장 많은 나라다. 2025년 전 세계 응시자 약 56.7만 명 중 약 8.6만 명(15.2%)이 베트남인이었다.
- 2026년부터 베트남 고교 졸업·대학 입시에서 TOPIK 3급 이상이 외국어 과목을 대신한다.
- 한국은 베트남 최대 투자국이다. 한국 기업에서 일하는 베트남인이 많고, 한국어를 할 줄 아는 인력에 대한 수요도 계속 크다.

### 2.2 문제
- 베트남어로 된 한국어 앱은 많다. 하지만 대표 앱(HeyKorea 등)은 한글부터 시작하는 **입문 코스형**이다.
- TOPIK 2~4급에서 정체된 사람에게 필요한 것은 **어휘량**이다. 그런데 이 구간 어휘를 체계적으로 늘려주는 앱은 약하다.
- 베트남인에게는 큰 자산이 있다. 한국어 한자어와 베트남어 Hán Việt 어휘는 소리와 뜻이 규칙적으로 대응한다(예: 준비 = chuẩn bị, 확인 = xác nhận). 그런데 대부분의 앱은 이 자산을 학습 구조로 쓰지 않는다. 한자음을 보여주는 사전 앱은 있지만, "찾아보기" 기능에 그친다.
- 직장인에게는 시험용 단어보다 **회사에서 바로 듣고 쓰는 한국어**(회의, 보고, 승인, 일정)가 필요하다.
- 비슷한 시도로 HanChin(베트남어-한국어, 한자 뿌리 학습 + 커뮤니티)이 있다. 그래서 차별점은 아이디어가 아니라 설계, 정확성, 실생활 문장, 진짜 목소리에서 나온다.

### 2.3 우리의 답
1. **한자어 다리**: 한국어 → 한자 → Hán Việt을 한 화면에서 잇는다. 외워야 할 단어를 이미 아는 단어로 바꾼다.
2. **함정 먼저**: 같은 한자인데 뜻이 다른 단어(정보 ≠ tình báo)를 분명히 알려준다. 실수를 막고, 첫인상에서 "이건 몰랐다"는 순간을 만든다.
3. **살아있는 지식**: 단어마다 회사에서 실제로 쓰는 문장 1개. 더 원하는 사람만 더 본다.
4. **간격 반복**: 잊기 직전에 다시 묻는다. 사람은 못 하고 앱은 잘하는 일이다.
5. **진짜 한국인 목소리**: 대표 문장은 한국어 원어민인 Max가 직접 녹음한다.

## 3. 제품 원칙 (판단 기준)

원칙끼리 부딪치면 위에 있는 것이 우선이다.

1. **정확성이 양보다 먼저다.** 한자, Hán Việt 음, 단어 유형 판정, 베트남어 번역이 틀리면 신뢰를 잃는다. 검수된 콘텐츠만 사용자에게 보인다.
2. **앱이 사람보다 잘하는 것만 한다.** 반복, 측정, 즉시 피드백, 대량 듣기에 집중한다. 자유 회화와 말하기 채점처럼 앱이 약한 것은 하지 않는다.
3. **모국어를 무기로 쓴다.** 모든 기능은 베트남어 화자이기 때문에 더 쉬워지는 지점을 찾는다.
4. **첫 1분 안에 가치를 준다.** 핵심 테스터는 매우 비판적이라, 지루하거나 유익하지 않으면 바로 그만둔다. 설명, 온보딩, 설문은 최소로 한다.
5. **압박 없는 습관을 만든다.** 하루 3~5분이면 충분하다. 하트 제한, 광고로 진도 막기, 연속 기록 압박, 알림 남발은 쓰지 않는다.
6. **단어 1개 + 문장 1개.** 문장이 많으면 압박이 된다. 기본은 1문장이고, 더 보기는 사용자가 고른다.
7. **증거로 결정한다.** 실제 사용 기록과 사용자의 말이 기획자(사람이든 AI든)의 생각보다 우선한다.

## 4. 누구를 위한 앱인가

### 1차 타깃
- 한국 기업(또는 한국계 법인)에서 일하는 베트남 직장인
- 한글은 읽을 수 있고, 수준은 TOPIK 2~4급
- 한국인 상사·동료의 메시지와 회의를 더 잘 알아듣고 싶다
- 출퇴근, 점심시간에 휴대폰으로 짧게 공부한다

### 핵심 테스터
- 가족 1명(TOPIK 3급, 한국계 회사 근무). 실제 사용자이자 베트남어 검수자다.
- 매우 비판적이다. 이 사람이 계속 쓰면 1차 타깃에게도 통한다고 본다. 다만 한국어 노출이 많은 환경이라 일반 학습자와 다를 수 있다. 그래서 외부 테스터 3~5명을 곧 추가한다.

### 지금은 타깃이 아님
- 한글을 처음 배우는 사람 (HeyKorea 등이 잘한다)
- 시험 문제 풀이만 원하는 사람

## 5. 핵심 학습 흐름 (현재 POC 기준)

1. **추측**: 한국어 단어와 소리를 보여주고, Hán Việt 음을 4지선다로 맞히게 한다. 아는 단어는 "이미 앎"으로 넘길 수 있다.
2. **다리 공개**: 한국어 음절, 한자(인주 도장 모양), Hán Việt 음을 세로로 잇는다. 단어 유형, 뜻, 짧은 설명, 같은 한자를 가진 단어를 함께 보여준다.
3. **실생활 문장**: 회사에서 쓰는 문장 1개(음성 + 베트남어 뜻). "예문 더 보기"를 누르면 2개씩 더 나온다.
4. **확인 퀴즈**: 새 단어 5개를 배운 뒤 섞어서 묻는다. 문장을 듣고 뜻 고르기, 빈칸에 맞는 단어 고르기. 함정 단어는 오답 보기에 그 함정 뜻을 넣는다.
5. **간격 반복**: 복습 간격은 1, 3, 7, 14, 30일. 틀리면 다음 날 다시 나온다.
6. **세션 끝**: 오늘의 함정 요약과 한 번 누르는 평가(지루함 / 보통 / 유익함), 선택형 한 줄 의견.

### 단어 유형
| 유형 | 뜻 | 예 |
| --- | --- | --- |
| A 같음 | 베트남어에서도 같은 뜻으로 쓴다 | 처리 = xử lý |
| B 다른 말 씀 | 한자음은 대응하지만 일상 베트남어는 다른 단어를 쓴다 | 회의 = hội nghị → cuộc họp |
| C 함정 | 뜻이 다르거나 일부만 겹친다 | 정보 ≠ tình báo → thông tin |

### 받침 대응 규칙 (학습 콘텐츠)
ㄱ → -c/-ch, ㄹ → -t, ㅂ → -p, ㅁ → -m, ㄴ → -n, ㅇ → -ng/-nh. 예외가 있다(예: 승 承 → thừa).

## 6. 콘텐츠 원칙

- **한자와 Hán Việt 음은 지어내지 않는다.** 출처는 다음과 같다.
  - 국립국어원 한국어기초사전: 표제어, 원어(한자), 등급, 예문, 베트남어 번역. CC BY-SA 2.0 KR이라 출처를 표시하고, 가공한 데이터는 같은 조건으로 공개한다.
  - Unicode Unihan kVietnamese: 한자 → 베트남어 독음. 독음이 여러 개거나 Nôm 독음이 섞일 수 있어 검수가 필요하다.
- **사전 데이터도 그대로 믿지 않는다.** 한-베 학습사전의 베트남어 뜻풀이에도 번역 오류가 보고되어 있다.
- **역할 분담**: 초안은 AI가 쓴다. 한국어 문장의 자연스러움은 Max가, 베트남어 번역과 유형 판정은 핵심 테스터가 확정한다.
- **검수 상태 표시**: 모든 단어에 reviewed 상태를 둔다. reviewed:true만 앱에 보인다.
- **예문 기준**: 회사, 일상, 뉴스처럼 실제로 듣게 될 상황. 해당 수준에 맞는 문법, 짧은 길이, 존댓말 중심.
- **음성**: 대표 문장은 Max가 녹음한다(같은 마이크, 조용한 방, 평소 속도). 녹음이 없으면 기계 음성으로 대신하고, 녹음이 생기면 교체한다.

## 7. 성공 지표와 판단 규칙

### 지표
| 지표 | 목표 | 어디서 보나 |
| --- | --- | --- |
| 주간 사용일 | 7일 중 5일 이상 | 앱 리포트 (사용한 날) |
| 세션 평가 | "유익함"이 과반, "지루함"은 드물게 | 앱 리포트 |
| 복습 정답률 | 80~90% (너무 쉽지도 어렵지도 않게) | 앱 리포트 (퀴즈 정답) |
| 30일 기억 유지 | 30일 전에 배운 단어의 소리 → 뜻 정답률 | 앱 데이터 |
| 세션 길이 | 3~5분 | 앱 데이터 |
| "이미 앎" 비율 | 너무 높으면 단어가 쉽다는 신호 | 앱 데이터 |

### 증거의 무게 (높은 순)
1. 실제 사용 기록(앱 리포트의 데이터)
2. 사용자가 직접 한 말(테스터 의견, Max가 옮긴 말)
3. 가상 사용자 리뷰(learner-critic 서브에이전트)
4. AI나 개발자의 아이디어

### 지표를 속이지 않는다
지표를 올리려고 학습 효과를 해치는 변경은 하지 않는다.
- 문제를 쉽게 만들어 정답률 올리기
- 알림이나 압박으로 재방문 올리기
- 세션을 늘려 사용 시간 부풀리기

## 8. 범위

### 지금 (POC → MVP)
- 검수된 직장 한자어 20개 → 단계적으로 100~500개
- 위 학습 흐름, 단어장, 받침 규칙 화면, 리포트 복사
- 대표 문장 녹음 도구와 녹음 음성 재생

### 다음 (증거가 생기면)
- 베트남인 맞춤 소리 구분 훈련(평음·경음·격음, 받침, 연음)
- 대상별 단어 팩(EPS-TOPIK 산업현장, 고교생 TOPIK 3급)
- 기기 간 진도 동기화와 사용 기록 자동 수집(Supabase 후보, 개인정보 최소화)
- 배운 단어로 한 문장 쓰기 → AI가 베트남어로 교정

### 하지 않을 것
- 회원가입, 결제, 광고, 하트 제한, 연속 기록 압박, 알림 남발
- React 등 프레임워크와 빌드 단계 (정적 사이트 유지)
- 자유 회화 AI 채팅, 말하기 점수
- 한글 입문 강좌
- 디자인 전면 개편 (흰 바탕, 먹색, 인주 빨강 #d7261e, 형광 노랑 강조 유지)
