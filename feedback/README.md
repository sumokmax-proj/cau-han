# feedback/ — 실제 사용 증거 (git 제외, 로컬 전용)

이 폴더의 파일은 커밋되지 않는다(.gitignore). 공개 저장소이기 때문이다. /plan-cycle은 로컬에서 이 폴더를 읽는다.

## 넣는 방법
1. 테스터가 앱의 "피드백" 화면 → "리포트 복사"로 보내준 내용을 받는다.
2. `feedback/YYYY-MM-DD.md` 파일을 만들고 아래 형식으로 붙여넣는다.

```
# YYYY-MM-DD

## 앱 리포트
(복사한 리포트 전체를 그대로)

## 테스터가 한 말 (들은 그대로)
- "..."

## Max가 본 것
- (옆에서 본 행동: 어디서 멈췄는지, 어디서 웃었는지, 언제 앱을 닫았는지)
```
